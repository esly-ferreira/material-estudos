Display inline e block

O display inline e block são dois tipos de display que podem ser usados para controlar como um elemento é exibido na página. O display inline é usado para exibir um elemento como uma linha, enquanto o display block é usado para exibir um elemento como um bloco. O display inline-block é usado para exibir um elemento como um bloco, mas com a possibilidade de ser inline.

Display inline

Inline

Inline block

Block

CSS 
.inline {
  display: inline;
  border: 1px solid red;
  margin: 4px;
}
.inline-block {
  display: inline-block;
  border: 1px solid red;
  margin: 4px;
}
.block {
  display: block;
  border: 1px solid red;
  margin: 4px;
}

Seletores modernos

Seletores modernos são regras do CSS que funcionam como filtros avançados. Um seletor é a mira que aponta para um elemento HTML e aplica um estilo, como cor ou tamanho.

Eles permitem regras complexas que antes exigiam código repetido ou JavaScript.

:is() e :where()

Encurtam o código quando o mesmo estilo vale para vários lugares. A diferença: o :where() não tem peso (especificidade), então é mais fácil sobrescrever depois.

:is()

header

main

footer

:where() sobrescrito no banner

card
banner
sidebar

:has()

O :has() funciona como uma regra de condição visual. Ele é conhecido como o seletor de pai.

Imagine várias caixas, os elementos pai. O :has() olha o conteúdo de cada caixa e cria a regra: se esta caixa tiver um item específico dentro dela, o elemento filho, mude a cor de fora da caixa.

Antes, o CSS só agia em uma direção: alterar o item de dentro a partir da caixa de fora. O caminho inverso exigia JavaScript. Agora o CSS faz isso sozinho.

Aviso comum

Este é um aviso sem urgência.

Aviso crítico

Falha no sistema!

Este cartão possui um alerta de erro.

HTML 
<!-- Cartão normal -->
<div class="cartao">
  <h2>Aviso comum</h2>
  <p>Este é um aviso sem urgência.</p>
</div>

<!-- Cartão de erro -->
<div class="cartao">
  <h2>Aviso crítico</h2>
  <span class="erro">Falha no sistema!</span>
  <p>Este cartão possui um alerta de erro.</p>
</div>
CSS 
/* CSS base para todos os cartões (tema escuro) */
.cartao {
  background-color: #1a1a1a;
  border: 1px solid #333;
  padding: 20px;
  margin-bottom: 15px;
  color: #fff;
}

/* A div.cartao que tiver .erro dentro ganha borda vermelha */
.cartao:has(.erro) {
  border: 2px solid #ff4444;
}

:not()

Aplica o estilo a todos os elementos, exceto o que você especificar.

  • Item 1
  • Ativo
  • Item 3
  • Item 4
CSS 
/* --- 1. :is() --- */
/* Jeito antigo, repetitivo: */
header p, main p, footer p { color: #ccc; }

/* Jeito moderno: */
:is(header, main, footer) p {
  color: #ccc;
}

/* --- 2. :where() --- */
/* Aplica o estilo, mas permite que seja facilmente sobrescrito */
:where(.card, .banner, .sidebar) a {
  text-decoration: none;
}

/* --- 3. :has() --- */
/* A .cartao que tiver .erro dentro ganha borda vermelha */
.cartao:has(.erro) {
  border: 2px solid #ff4444;
}

/* --- 4. :not() --- */
/* Opacidade em todos os itens, menos o .ativo */
li:not(.ativo) {
  opacity: 0.5;
}

Aspect ratio

O aspect-ratio define a proporção entre a largura e a altura de um elemento. Ele funciona como uma moldura fixa para quadros ou telas.

Se a moldura é retangular e a largura aumenta, o navegador calcula a altura sozinho para manter o formato. Antes, era preciso calcular a altura na mão para vídeo e imagem não amassarem em telas diferentes.

16 / 9 e 1 / 1

HTML 
<div class="video"></div>
<img class="avatar" src="perfil.jpg" alt="Avatar">
CSS 
.video {
  width: 100%;
  /* 16 de largura para 9 de altura: proporção de vídeo */
  aspect-ratio: 16 / 9;
  background-color: #2a2a2a;
}

.avatar {
  width: 150px;
  /* quadrado perfeito */
  aspect-ratio: 1 / 1;
  border-radius: 50%;
  object-fit: cover; /* preenche a moldura sem deformar */
}

Deixar o CSS calcular a altura torna o layout responsivo mais rápido e o código mais limpo.

Content visibility

O content-visibility é uma ferramenta de performance. Ele funciona como um modo soneca para partes do código.

Em vez de o navegador desenhar a página inteira de uma vez, a regra avisa: só processe essa seção quando o usuário rolar e chegar perto dela.

O problema

Em páginas muito longas, o carregamento inicial fica lento e pode travar o aparelho. Com essa regra, o navegador ignora a matemática visual do que está fora da tela, e o começo da página aparece quase na hora.

contain-intrinsic-size

Se o navegador não desenha o elemento, a altura dele vira zero. Quando a seção entra na tela, a barra de rolagem salta. O contain-intrinsic-size reserva um tamanho aproximado antes do conteúdo ser processado.

Muitos dados aqui

Esta caixa só é desenhada quando chega perto da tela. A reserva de altura evita o salto da rolagem.

HTML 
<!-- Seção pesada: rodapé complexo ou lista de comentários -->
<section class="secao-pesada">
  <h2>Muitos dados aqui</h2>
  <!-- Centenas de elementos HTML -->
</section>
CSS 
.secao-pesada {
  /* renderiza só quando chega perto da tela */
  content-visibility: auto;

  /* reserva 800px para a rolagem não pular */
  contain-intrinsic-size: 800px;

  background-color: #1a1a1a;
  border: 1px solid #333;
}

Transition

O transition controla a velocidade e a suavidade de uma mudança visual. Em vez de um corte seco, ele anima o caminho entre um estado e outro.

Sem ele, a lâmpada liga e desliga de uma vez. Com ele, o interruptor vira um dimmer: a luz acende e apaga aos poucos.

O que declarar

A regra fica no estado original do elemento. Ela define o que muda, quanto tempo dura e o ritmo.

background-color, transform ou all escolhem a propriedade. 0.3s é a duração. ease começa rápido e termina devagar; linear mantém a velocidade constante.

HTML 
<button class="botao-turbo">Adicionar ao Carrinho</button>
CSS 
.botao-turbo {
  background-color: #1a1a1a;
  color: #fff;
  border: 1px solid #333;
  padding: 15px 30px;
  font-size: 16px;
  cursor: pointer;

  /* qualquer mudança demora 0.3s em ritmo suave */
  transition: all 0.3s ease;
}

.botao-turbo:hover {
  background-color: #333;
  border-color: #666;
  transform: scale(1.05);
}

Movimento

Transform, animation e view transition ditam como as coisas se movem e mudam de formato. Cada um resolve um tipo diferente de mudança.

Transform

Altera a geometria: mover, girar, crescer ou encolher, sem empurrar o que está ao redor. Sozinho ele só troca o estado. Junto com transition, a troca fica suave.

Passe o mouse

Animation

O transition só vai do ponto A ao B, em geral no hover. O animation monta um filme com vários passos, sozinho e em loop, usando @keyframes como linha do tempo.

Atenção

View transition

Cria uma passagem suave entre telas ou grandes partes do layout. O navegador fotografa a tela antiga e a nova e interpola as duas. Antes, isso pedia bibliotecas de JavaScript.

O view-transition-name marca o elemento. Quando o estado muda, essa imagem vai da posição antiga para a nova sem corte seco.

HTML 
<div class="caixa-transform">Passe o mouse</div>
<div class="caixa-animada">Atenção</div>
<img class="imagem-destaque" src="carro.jpg" alt="Carro">
CSS 
/* --- 1. Transforms --- */
.caixa-transform {
  background-color: #1a1a1a;
  border: 1px solid #333;
  padding: 20px;
  width: 150px;
  transition: transform 0.3s ease;
}

.caixa-transform:hover {
  transform: translateY(-10px) scale(1.1);
}

/* --- 2. Animations --- */
.caixa-animada {
  background-color: #ff4444;
  padding: 20px;
  width: 150px;
  animation: pulso 2s infinite;
}

@keyframes pulso {
  0% { transform: scale(1); opacity: 1; }
  50% { transform: scale(1.05); opacity: 0.8; }
  100% { transform: scale(1); opacity: 1; }
}

/* --- 3. View Transitions --- */
.imagem-destaque {
  view-transition-name: transicao-carro-principal;
}

Troca de Tema

Propriedades customizadas e preferência de tema do sistema.

Propriedades Customizadas

Também conhecidas como variáveis CSS (custom properties), permitem definirmos valores no CSS que podem ser reutilizados no nosso código.

A propriedade é herdada pelos elementos filhos. É comum definirmos as mesmas nos elementos :root ou html, assim teremos acesso à propriedade em todos os elementos do site.

--roxo: #caf — define uma propriedade customizada.

var(--roxo) — a função var utiliza uma propriedade customizada.

CSS 
:root {
  --tamanho-titulo: 3rem;
  --cor-primaria: #84e;
}

h1 {
  font-size: var(--tamanho-titulo);
  color: var(--cor-primaria);
}

prefers-color-scheme

A @media prefers-color-scheme executa o código CSS conforme a preferência de tema do usuário. Funciona da mesma forma que o media query com max-width, porém em relação ao modo escuro (dark) ou claro (light).

CSS 
:root {
  --fundo: #fff;
  --texto: #111;
}

@media (prefers-color-scheme: dark) {
  :root {
    --fundo: #111;
    --texto: #fff;
  }
}

body {
  background: var(--fundo);
  color: var(--texto);
}
